Дата: 30 октября 2026. База: загруженный `Amaliyot-copy.zip`.

## PDF

Добавлены приватные маршруты результата и сертификата, режимы inline/attachment, Unicode-шрифты, перенос строк, страницы и no-store. Отозванный сертификат получает явную отметку. Активный незавершённый экзамен не выгружается. Ошибки при запросе PDF остаются JSON. Шрифты DejaVu включены вместе с лицензией.

## Swagger

Существующая интеграция springdoc сохранена и дополнена. Добавлены русское описание сценария, примеры demoUser/demoAdmin, регистрации, профиля и ответов. Бинарные PDF и ошибки описаны в OpenAPI. Для публичного контакта поддержки убрана ошибочная отметка обязательной авторизации. В prod документация отключена по умолчанию и включается через SWAGGER_ENABLED.

## Дополнительные возможности

1. Ограничение auth-запросов по адресу клиента: 20 запросов/60 секунд, ограниченная таблица, 429 с Retry-After. Дополняет существующую защиту по логину.
2. Изолированный demo profile с 40 вопросами, учеником, администратором, готовым результатом и сертификатом. Демобаза только в памяти, по умолчанию локальный интерфейс. Повторный запуск наполнения не создаёт дубли.

Также добавлены Dockerfile/Compose с постоянными томами, проверка Java 17 в CI, отдельная PostgreSQL-проверка, инструкции и скрипт HTTP-проверки демо.

## Совместимость

Основные версии Spring Boot 4.1.1, springdoc 3.1.1 и Java 17 сохранены. Для PDF добавлен Apache PDFBox 3.0.8. Маршруты существующего API сохранены; новые PDF-маршруты дополняют JSON. Структура БД и старые миграции V1-V13 не изменялись. Старые парольные хеши обновляются при успешном входе.

В поставке нет исходного `.env`, IDE-метаданных, Maven-кэша или пользовательских баз. Для существующего развертывания укажите свою базу через DB_URL и сделайте обычную резервную копию перед обновлением.

## Что требует отдельного подключения

Восстановление пароля по SMS/email требует настоящего провайдера доставки и остаётся 503. Для публичного размещения нужны выбранный хостинг, домен и HTTPS. Ограничение запросов в нескольких экземплярах приложения требует общей точки учёта. Полноценный пользовательский frontend не входит в эту задачу.
